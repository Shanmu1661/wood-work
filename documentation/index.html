1. Quick Start & Setup

TimberCraft is a clean, dependency-free static website template built exclusively with modern HTML5, Tailwind CSS utilities, custom modular CSS, and vanilla ES6+ JavaScript. No build step or package manager is mandatory to start customizing!

# Option A: Local preview with Python built-in server

python -m http.server 8000

# Then navigate to: http://localhost:8000


# Option B: Node.js npx serve

npx serve .


# Option C: VS Code Live Server extension

Right-click index.html or pages/index.html -> "Open with Live Server"

--wood-walnut #23150f (Deep Walnut)
--wood-oak #c4884d (Golden Oak)
--wood-brass #d4af37 (Artisan Brass)

4. Typography & Fonts

TimberCraft imports two Google Fonts:

  • Cinzel (Serif): Applied to statement headings (.font-serif) for that timeless luxury craftsman atelier signature.
  • Plus Jakarta Sans (Sans-Serif): Applied to body text and technical specifications for crisp legibility across all screen sizes.

5. Dark Mode & RTL Implementation

Dark Mode: Enabled by toggling the dark class on <html>. User preference is saved in localStorage.getItem('timbercraft_theme'). It also listens automatically to the user’s operating system preference (prefers-color-scheme).

RTL (Right to Left): Enabled by setting dir="rtl" on <html>. The custom rtl.css file automatically flips text alignment, arrow icons, breadcrumb chevrons, form inputs, and modal positioning for Arabic, Hebrew, or Persian languages.

All forms are equipped with client-side regex validation, floating error tooltips, and success toast popups:

Google Maps API:

Replace the container in contact.html with your Google Maps embed iframe or JavaScript Map API key.
